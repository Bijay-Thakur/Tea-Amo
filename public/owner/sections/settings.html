Backup / Recovery

Persistent data model: menu changes are preserved exactly as saved and are not rebuilt from the original seed. Clearing the dashboard never deletes transaction history or operational records.

Clear Dashboard Only

This only resets the numbers shown on the Dashboard to zero. Nothing is deleted. Sales, bills, reports, inventory, recipes, staff, attendance, vendors, expenses, customers, purchases, wastage, Z-reports and movement history all remain intact.

Reset Behavior

Dashboard-only reset is active. Resetting TEA AMO now clears only the Dashboard display baseline. Staff, attendance, orders, sales history, inventory, vendors, expenses, customers, recipes, tables and all other operational data remain intact.

Complete Operational Reset

Use this only when you want to start fresh. It clears sales, bills, table orders, attendance history, expenses, purchases, wastage, customers, inventory movement history, business-day/Z-report history and owner-capital transactions. Inventory quantities and average costs are reset to zero. Your menu/prices, recipes, staff profiles, vendors, business settings, payment methods/QRs and owner password are preserved.
